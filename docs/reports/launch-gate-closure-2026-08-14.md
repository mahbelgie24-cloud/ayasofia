## 3. قائمة الأسرار المطلوبة للإنتاج (P0-6)

هذه هي المتغيرات التي يجب وضعها في بيئة الاستضافة (Vercel) عند الإطلاق.
القيم المعلّمة بـ "موجودة في .env.local" انسخها كما هي.

| المتغير                                 | الوصف                                        | المصدر                                             |
| --------------------------------------- | -------------------------------------------- | -------------------------------------------------- |
| `NEXT_PUBLIC_SUPABASE_URL`              | رابط مشروع Supabase                          | موجود في `.env.local` (انسخه)                      |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY`         | المفتاح العام (آمن للواجهة)                  | موجود في `.env.local` (انسخه)                      |
| `SUPABASE_SERVICE_ROLE_KEY`             | المفتاح السري (خادم فقط)                     | موجود في `.env.local` (انسخه)                      |
| `DATABASE_URL`                          | رابط قاعدة البيانات مع `connection_limit=10` | موجود في `.env.local` (انسخه)                      |
| `WIFI_DEVICE_ID_SALT`                   | ملح تشفير أجهزة الواي فاي                    | `52d8a5b07694180acb165171d2801560179c5949e2af42c0` |
| `CAPTIVE_PORTAL_ADAPTER`                | محول الراوتر                                 | `mock` (حتى حسم نوع الراوتر)                       |
| `RUN_ENV`                               | وضع التشغيل                                  | `production`                                       |
| `NEXT_PUBLIC_SENTRY_DSN` / `SENTRY_DSN` | مراقبة الأخطاء (اختياري)                     | أنشئ مشروع Sentry مجاني إن أردت                    |

**ملاحظة:** قيمة `WIFI_DEVICE_ID_SALT` أعلاه ولّدتها لك عشوائياً — استخدمها كما هي في الإنتاج، أو ولّد قيمة جديدة (يجب أن تكون نفسها في كل مكان).

## 4. Release Gate Recommendation (محدّثة)

**NO-GO للإطلاق الفوري → Conditional Go.**

- **مغلق:** P0-1، P0-2، P0-4، P0-7.
- **المانعان المتبقيان:** P0-3 (القائمة الحقيقية) ثم P0-5 (التشغيل الموازي).
- **لا عيب برمجي حرج** — الإطلاق ينتظر جاهزية القائمة فقط.

---

## 5. الخطوات المتبقية

1. تجهيز القائمة الحقيقية (P0-3) → تعبئة `docs/real-menu-template.json` → `docs/real-menu.json`.
2. استيرادها: `npx tsx scripts/ingest-real-menu.ts` (نسخ احتياطي تلقائي).
3. وضع الأسرار أعلاه في بيئة الاستضافة (P0-6).
4. التشغيل الموازي أسبوعياً (P0-5): مقارنة Z-report بالعد اليدوي يومياً.
5. عند النجاح → القطع الكامل.
