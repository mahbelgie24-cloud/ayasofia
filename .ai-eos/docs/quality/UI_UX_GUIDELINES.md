- الإنجليزية ثانوية (حقول `nameEn` للرجوع)

- الأسعار: `XX.XX ₪` (الرمز بعد الرقم)

## ٢. الألوان (Brand Color System)

**المصدر المُعتمد:** `docs/technical-spec.md` §11.2 + `app/globals.css`

### ٢.١ قاعدة الخطأ ≠ الأحمر

```
brand.red (#DC0000)  → CTAs, تحديد, علامة تجارية
status.error (#9F1239) → فشل, إجراء مدمر
```

العلامة التجارية حمراء. لو كان الخطأ أحمر أيضًا = لا يستطيع الموظف التمييز بين "زر أساسي" و "خطر" بلمحة.

### ٢.٢ خلفيات الشاشات

| الشاشة        | الخلفية                   | السبب                      |
| ------------- | ------------------------- | -------------------------- |
| `/pos`        | `brand-cream`             | راحة العين لـ ٨ ساعات دوام |
| `/drive-thru` | `brand-cream`             | سرعة قراءة                 |
| `/kitchen`    | `brand-cream`             | تباين عالي مع البطاقات     |
| `/order`      | `brand-cream` + Hero أحمر | الأكثر جرأة (استخدام قصير) |
| `/admin`      | `brand-cream`             | هدوء لاتخاذ القرار         |

### ٢.٣ لا تستخدم الأحمر كخلفية كاملة لشاشات الموظفين

Red background لـ ٨ ساعات = إجهاد بصري. الأحمر للفت الانتباه فقط (أزرار، وسوم، إشعارات).

## ٣. الخطوط (Typography)

### ٣.١ الاستخدامات

```css
font-heading → Baloo 2 (Latin) / Baloo Bhaijaan 2 (Arabic)
  - عناوين الفئات
  - أسماء المنتجات
  - أرقام الطلبات في KDS
  - Hero في صفحة العميل

font-sans → Inter (Latin) / Noto Sans Arabic (Arabic)
  - الأسعار
  - قوائم المنتجات
  - جداول الإدارة
  - النماذج
```

**القاعدة:** Baloo للمسات العلامة التجارية. Inter/Noto للبيانات الكثيفة. لا تستخدم الخط السميك (Baloo) في جداول الأرقام — يضر بالوضوح.

## ٤. الزوايا والأشكال (Shape Language)

### ٤.١ مبدأ "لا زوايا حادة"

كل عنصر في العلامة التجارية (الشعار، الكوب، القشة، اللآلئ) دائري. الواجهة يجب أن تعكس ذلك:

```css
/* الأزرار الأساسية */
rounded-full   /* pill shape — CTA buttons */

/* البطاقات والحاويات */
rounded-2xl    /* 16px — product cards, modals */

/* الحقول والمدخلات */
rounded-lg     /* 8px — inputs */
rounded-full   /* search bars, phone inputs */
```

### ٤.٢ الأيقونات

- **lucide-react** هو مصدر الأيقونات المعتمد
- استخدم `size-5` أو `size-6`
- لا تخصص stroke width حاليًا (lucid icons تأتي بـ 2px stroke — يطابق دليل العلامة التجارية)

## ٥. أحجام اللمس (Touch Targets)

| السطح               | الحد الأدنى | موصى به              |
| ------------------- | ----------- | -------------------- |
| أزرار POS           | **44px**    | 48px — تحت ضغط الوقت |
| أزرار Drive-Thru    | **44px**    | 48px — ضغط أكبر      |
| أزرار العميل (جوال) | **44px**    | —                    |
| صفوف الجداول        | **40px**    | 44px                 |

**القاعدة:** WCAG 2.2 AA توصي بـ 24px. لـ POS تحت الضغط: 44px هو الحد الأدنى العملي.

## ٦. الحركة (Motion)

تستخدم `tw-animate-css`:

- **Spring easing** للتفاعلات (bounce on add-to-cart)
- **لا linear transitions** — تتعارض مع لغة التصميم الدائرية الناعمة
- KDS: طلب جديد = تأثير دخول + صوت

```html
<!-- مثال: زر إضافة للسلة -->
className="transition-all duration-200 ease-spring hover:scale-105 active:scale-95"
```

## ٧. أسطح محددة (Per-Surface Application)

### ٧.١ `/pos` — نقطة البيع

- أزرار فئات: pill-shaped
- بطاقات منتجات: `rounded-2xl`، ٢-٤ أعمدة حسب العرض
- زر السلة: pill، أحمر كامل، مثبت في الأسفل
- نافذة المُعدِّلات: bottom sheet على الجوال، modal على الشاشات الكبيرة

### ٧.٢ `/drive-thru` — مسار السيارات

- نفس نظام POS لكن **أكثف** (٣-٥ أعمدة)
- تصنيف bubble-tea أولاً
- لا عناصر زخرفية
- Header بارز: 🚘 أحمر

### ٧.٣ `/kitchen` — المطبخ

- أكبر خط في النظام (أرقام الطلبات: `text-2xl`)
- بطاقات بحالة لونية واضحة:
  - برتقالي = received
  - أصفر = preparing
  - أخضر = ready
- صوت تنبيه عند طلب جديد (WAV inline base64)

### ٧.٤ `/order` — طلب العميل

- الأكثر توجهاً للعلامة التجارية
- Hero header أحمر مع شعار
- صور منتجات (أيقونات SVG للبذور، صور حقيقية لاحقًا)
- تأثير bounce عند الإضافة للسلة
- شبكة عمودين (mobile-first)

### ٧.٥ `/admin` — الإدارة

- الأكثر هدوءًا
- Sidebar يمين (RTL)
- جداول نظيفة
- أزرار حمراء فقط للأفعال الأساسية
- رسوم بيانية بألوان محايدة (قيد التطوير)

## ٨. الإيصالات (Receipts)

- **واتساب:** نص عادي (plain text). `buildReceiptText()` يولده.
- **طباعة:** نص عادي. طابعة حرارية 80mm تطبع نصًا فقط.
- **شعار الطابعة:** نسخة سوداء من الأيقونة (مطلوبة قبل Phase 1 — spec §11.6)

## ١٠. الوصول (Accessibility)

- [ ] كل الأزرار لها `aria-label` (إن كانت أيقونة فقط)
- [ ] كل الصور لها `alt` نصي
- [ ] تباين ألوان: 4.5:1 على الأقل للنص العادي (WCAG AA)
- [ ] التركيز (focus): مرئي على كل العناصر التفاعلية
- [ ] لا تعتمد على اللون وحده لنقل المعلومات (اسأل: هل colorblind سيفهم؟)
- [ ] `role="alert"` على رسائل الخطأ
