## افتراضات النطاق (Scope Assumptions)

1. **متجر واحد:** كل التطوير يفترض متجرًا واحدًا. قاعدة البيانات جاهزة للتوسع لكنه ليس مبنيًا.
2. **عملة ₪ (ILS):** قابلة للتغيير عبر settings دون تعديل الكود.
3. **لا دفع إلكتروني:** يفترض cash أو جهاز بطاقات خارجي.
4. **طابعة حرارية:** يُفترض وجودها. ليس من نطاق v1 دعم طابعات متعددة.
5. **الموظفون < 20:** تصميم PIN login يفترض متجرًا صغيرًا.
6. **بيانات seed تجريبية:** يجب استبدالها ببيانات حقيقية قبل الإطلاق.
