## ١. ما هذا المشروع؟

نظام تشغيلي داخلي لمحل حلويات متخصص في شاي الفقاعات (Bubble Tea) والحلويات اليابانية/الكورية في قلقيلية. يشمل:

- **نقطة بيع (POS):** إدخال سريع للطلبات عبر الموظفين
- **Drive-Thru:** واجهة مخصصة لمسار السيارات
- **طلب ذاتي:** صفحة للعملاء عبر QR Code (بدون تطبيق)
- **شاشة المطبخ (KDS):** عرض مباشر للطلبات قيد التحضير
- **مخزون:** تتبع تلقائي للمواد الخام عبر وصفات (BOM)
- **تقارير:** يومية/أسبوعية، أفضل المبيعات، هوامش الربح، Z-report
- **إدارة:** الموظفين، القائمة، الإعدادات

## ٤. المبادئ الهندسية المعتمدة

1. **Monolith نمطي (Modular Monolith):** تطبيق واحد منظم في وحدات واضحة (POS, Inventory, Ordering, Admin). لا حاجة للـ microservices.
2. **لا ثقة في العميل:** الأسعار تُعاد حسابها server-side دائمًا. العميل مجرد واجهة عرض.
3. **Idempotency أولاً:** كل عملية بيع تُنشئ مفتاح idempotencyKey. لا ازدواجية في الأوامر أبدًا.
4. **Atomic transactions:** كل الخصومات (مخزون، أوامر) ضمن معاملة قاعدة بيانات واحدة.
5. **الأمان متعدد الطبقات:** Proxy (UX) ← Server Action (Auth) ← RLS (DB) ← Service Role (admin ops)
6. **تمثيل المال بـ integer minor units:** الأسعار تُخزن كـ `numeric(10,2)` وتُحسب بـ agorot (وحدات صحيحة). لا float أبدًا.
